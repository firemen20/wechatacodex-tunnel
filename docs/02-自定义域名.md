# 自定义域名（加密 443 模式）

> 有条件就上这个模式：全链路加密、更稳定、多种客户端全支持。

---

## 一、前置判断：你的域名能被 Cloudflare 接受吗

Cloudflare 只接受**公共后缀列表（PSL）里的后缀 + 一级**。判断方法：

```bash
curl -s https://publicsuffix.org/list/public_suffix_list.dat | grep -x "你的后缀"
```

| 域名 | 上级在 PSL？ | CF 接受？ |
|---|---|---|
| `node1.example.com` | `com` ✅ | ✅ |
| `node1.myname.github.io` | `github.io` ✅ | ✅ |
| `node1.abc.freedomain.cn` | `freedomain.cn` ❌ | ❌ |

**不通过的表现**：
```
Please ensure you are providing the root domain and not any subdomains
```

## 二、四步走

### 第 1 步：在 Cloudflare 建 zone

1. dash.cloudflare.com → **添加站点**
2. 输入域名（**只输域名本身**，不加 `https://`、不加 `www.`、不加斜杠）
3. 选 **Free** 套餐
4. ⭐ **页面会显示 2 个真实 NS**，形如：
   ```
   celeste.ns.cloudflare.com
   harlan.ns.cloudflare.com
   ```
   **原样抄下来**（每台分配的单词不同，以你页面上显示的为准）

此时状态是 `Pending`，正常。

### 第 2 步：去注册商改 NS

到域名注册商面板找 **「DNS服务器 / Nameservers / 自定义 NS」**：

- 切换到「使用自定义 NS」
- **删掉默认的那些**，只留上一步抄下的两个
- 保存

> ⚠️ 顺序不能反：**先建 zone 才有 NS 可填**。

### 第 3 步：等激活

CF 面板上 `Pending` → **`Active`**，通常几分钟到几小时。

诊断命令（公共 DoH 只会返回 SERVFAIL，看不出原因，要直接问权威服务器）：
```bash
node tools/dns-query.js 你的域名 NS a.ns.<上级NS服务器>
```

### 第 4 步：把域名绑到 Worker

```bash
CF_API_TOKEN=xxx CF_ACCOUNT_ID=yyy \
  node tools/bind-custom-domain.js example.com my-worker-a my-worker-b --prefix node
```

这会分配 `node1.example.com` → `my-worker-a`，`node2.example.com` → `my-worker-b`。

**如果报 `10405 Method not allowed for this authentication scheme`**（账户级 token 用不了 Custom Domains 端点），改用 Workers Route：

1. 建 **proxied 的 A 记录**：`node1` → `192.0.2.1`（内容随意，Worker 会接管）
2. 建 **Workers Route**：`node1.example.com/*` → `my-worker-a`

## 三、配置里怎么写

```jsonc
{
  "domain": "example.com",
  "workers": [
    { "tag": "node1", "script": "my-worker-a", "uuid": "…", "host": "node1.example.com" }
  ]
}
```

`build-nodes.js` 会自动识别为自定义域名模式，生成：

```yaml
- name: node1-172-66-0-1-443tls
  type: vless
  server: 172.66.0.1          # 裸 IP：避开 DNS 污染
  port: 443
  tls: true                   # TLS 加密
  servername: node1.example.com   # SNI 用自定义域名（未被阻断）
  ws-opts:
    headers:
      Host: node1.example.com
```

**为什么 server 仍用裸 IP 而不是域名？**
避免 DNS 污染。域名只用来做 SNI/Host（那一层不走 DNS 解析，是握手时直接填的）。

证书由 Cloudflare 自动签发和续期（Universal SSL），不用管。

## 四、验证

```bash
# 域名是否可达且证书正确
curl -sv --max-time 20 "https://node1.example.com/" 2>&1 | grep -E "subject|issuer|HTTP/"

# 完整验证节点
node tools/verify-config.js dist/ClashMeta-FlClash.yaml dist/verify.json
```

## 五、常见问题

**Q: NS 改了很久还是 pending？**
- 确认注册商那边**只有 CF 那两个 NS**（残留默认 NS 会导致委派混乱）
- 用 `tools/dns-query.js` 直接问上级权威服务器，看委派到底指向谁

**Q: 证书一直没签发？**
Universal SSL 对新 zone 可能要几分钟到几小时。CF 面板 → SSL/TLS → Edge Certificates 可以看到状态。

**Q: 想换域名怎么办？**
改 `config.json` 里的 `domain` 和各 `host`，重新绑一次即可。代码不用动。

**Q: 单域名会不会是单点？**
会。如果要更高可用性，可以注册**两个免费域名**分别绑同一批 Worker，配置里同时生成两套节点。
